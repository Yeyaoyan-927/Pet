# 行为训练与常见问题矫正

## 一、先排医学原因，再谈行为矫正

任何“突然出现”的行为问题，第一步都是排除疾病：

- 乱尿 / 乱拉 → 泌尿道感染、结石、糖尿病、关节炎（蹲不下砂盆）
- 突然乱叫 / 夜间嚎叫 → 疼痛、甲状腺功能亢进（猫）、认知障碍（老年）
- 食欲变化 + 脾气变差 → 牙科疾病、腹痛
- 过度舔毛 → 皮肤瘙痒、过敏、疼痛、应激

**没有排除医学原因就做行为矫正，通常无效且会延误治疗。** 门店的建议顺序永远是：先就医排查，再做训练。

## 二、正向训练的四条基本规则

1. **奖励即时**：行为发生后 1~2 秒内给奖励才有效，晚了就奖励了别的动作。
2. **一次只教一个动作**，每次 3~5 分钟，一天多次；长时间训练反而降低效率。
3. **不看“错误”，看“替代行为”**：不奖励乱叫，但要给出“安静时才有奖励”的通路。
4. **拒绝体罚**：拍打、按头、电击项圈会造成恐惧关联，导致攻击性升级与信任破坏。AVSAB 明确反对以惩罚为主的训练。

口令一致：同一动作全家用同一个词，手势也统一。家庭成员轮流练，避免“只有一个人叫得动”。

## 三、拆家：先分清是分离焦虑还是无聊

| 特征 | 分离焦虑 | 无聊 / 精力过剩 |
| --- | --- | --- |
| 发生时间 | 主人离开后 30 分钟内 | 全天任何时候 |
| 破坏对象 | 门框、窗台、主人衣物（带气味） | 随机，多為可咬物 |
| 伴随行为 | 嚎叫、随地排泄、流口水、抓门 | 一般安静，事后无应激 |
| 主人回家时 | 极度兴奋、贴身 | 平常 |

**分离焦虑**的矫正核心是“淡化出门与回家仪式”：出门前 10 分钟不理它，回家后 5 分钟内不打招呼；从离开 1 分钟开始阶梯式延长，每次成功才加时。中重度需配合行为科医生，必要时药物辅助。

**无聊型**靠环境丰容：漏食玩具、嗅闻垫、每日 30~60 分钟嗅闻散步（嗅闻比奔跑更耗神）、固定训练时间。

## 四、乱叫：按叫声类型分流

- **警戒吠叫**（门铃、脚步声）：改变环境线索——先放录音低音量脱敏，同时让“门铃 = 去垫子上等零食”，把警戒转成期待。
- **寻求关注吠叫**：**完全不回应**（不看不说不摸），安静 2 秒立刻奖励。只要回应一次（哪怕呵斥），就是强化。
- **分离焦虑吠叫**：按上一节的淡化仪式处理。
- **兴奋 / 游戏吠叫**：暂停游戏直到安静，重新开始时降低强度。

猫的夜间嚎叫：先排查甲状腺与认知障碍，再看白天是否睡太多——增加白天互动与喂食 puzzle。

## 五、护食：脱敏 + 反条件化

护食是资源保护行为，**不要抢、不要惩罚**，会升级为咬人。分四步：

1. 距离训练：人站在它吃饭时不会紧张的距离，扔一块更高价值的零食进碗，然后走开。
2. 逐步靠近：每次靠近半步，扔零食、离开，重复到它能放松。
3. 触碰碗：靠近后轻碰碗沿再扔零食，让它建立“人靠近 = 更好的东西出现”。
4. 手喂与交换：用“交换游戏”教它“给我 → 还你更好的”。

幼犬期就要做“碗边加料”预防；有咬人史的个体建议转行为专科，不要自行加压。

## 六、猫乱尿：数量、尺寸、清洁三件事

猫乱尿最常见的三个非医学原因，按顺序排查：

1. **砂盆数量不足**：经验法则是 **N+1**（两只猫三个盆），且分散在不同位置，不能并排。
2. **砂盆太小**：长度建议为猫**体长的 1.5 倍**（不含尾巴），多数市售“幼猫盆”对成猫都偏小。
3. **清洁频率不够**：每日至少铲两次，每周彻底换砂清洗；用无香清洁剂，避免柑橘与氨类气味。

其他因素：猫砂突然更换（同品牌不同批次也可能）、砂盆位置太吵或靠近食盆、被其他猫堵截、家中新增成员。

**行为标记 vs 排泄**：站立、尾巴竖起、喷少量尿在垂直面 = 标记行为（多与领地/应激相关）；蹲下大量排尿 = 排泄问题。两者处理路径不同。

## 七、社会化窗口期与预防

犬的社会化关键期约 **3~16 周龄**，猫约 **2~7 周龄**。窗口期内以正向体验接触不同人、环境声音、同类、被触摸（爪、耳、口）。

错过窗口期不是“没救了”，只是需要更慢的脱敏节奏：每次暴露强度控制在它还能吃零食的程度，一旦拒食就是超过阈值，要退回去。

## 八、磨爪与猫抓板

猫磨爪是正常行为，不是“破坏”。要解决的是“抓错地方”，不是“不抓”：

- 提供**竖直**抓板（可伸展全身）与**水平**抓板各一，材质优先剑麻 / 瓦楞纸。
- 位置比数量重要：放在它醒来后必经之路、沙发旁，而不是塞在角落。
- 抓板必须稳固，晃动会让猫放弃使用。
- 在错误位置贴双面胶或临时覆盖，同时在正确位置撒猫薄荷引导。

## 九、训练记录与门店配合

门店可协助的部分：寄养期间的日程稳定性、分离焦虑犬的单独安置与嗅闻活动、老年犬的低强度活动安排。

行为矫正周期通常以**周**为单位，4~6 周看不到变化需要重新评估方案（或转行为专科）。给宠主的预期要说清：没有“三天见效”的行为训练。
