# 洗护前皮肤检查与异常识别

## 一、为什么必须"先看后洗"

犬猫的皮肤病在洗护前往往只有轻微表现，一旦下水、吹风、使用不当浴液，可能在数小时内迅速扩散或加重。门店在接宠后、下水前必须完成一次不少于 2 分钟的全身皮肤检查，并把结果记录到洗护记录的"皮肤毛发状况"字段。这一步是把责任边界讲清楚的关键：既保护宠物，也保护门店。

## 二、检查顺序（固定动作，避免漏检）

1. **先看整体**：站立位观察被毛是否成片脱落、是否有对称性秃斑、体表是否有异味。
2. **再摸体表**：用手掌逆毛抚摸背部、腰部、尾根、四肢内侧，感受是否有结痂、丘疹、硬块、油腻感。
3. **重点五个部位**：耳道外口与耳廓内侧、趾间与脚垫、腋下与腹股沟、肛周、眼周。
4. **最后翻开看**：发现异常处轻轻拨开被毛拍照，记录位置（左前肢 / 腰背部等）与形态（红斑 / 结痂 / 渗出）。

## 三、常见异常与处置口径

- **红斑、丘疹、抓痕**：多为过敏或急性皮炎表现。降低水温至 37℃ 左右，使用低敏、无香精浴液，避开患处过度搓洗。
- **结痂、渗出、异味明显**：先不水洗，用宠物专用湿巾做局部清洁并告知宠主，建议就医确认后再安排洗护。
- **对称性脱毛 + 皮屑增多**：可能涉及内分泌或营养问题，不做判断，只记录并建议就医。
- **趾间红肿、频繁舔咬**：注意趾间是否潮湿，洗后必须彻底吹干趾缝，否则易复发。
- **发现活的寄生虫（跳蚤、蜱虫）**：单独隔离处理，工具专用，洗护结束后对浴缸、毛巾、吹水机头做消毒。

## 四、必须停手并告知宠主的情况

出现下列任一情况，**不得继续洗护**：皮肤大面积破溃、渗血、明显疼痛抗拒触碰、疑似传染性皮肤病（环形脱毛、厚痂）、体温异常或精神沉郁。门店只做记录与转达，不做诊断、不开药、不建议具体药名。

## 五、记录与留痕

检查结果至少包含：检查时间、检查人、异常部位、形态描述、是否拍照、是否已告知宠主。异常照片随洗护记录留存，便于复诊对比与责任界定。
